# 词页 · 牛津高阶四步讲词

一个为 iPad Safari 设计的词典 / 讲词应用。查一个词，按「义 → 考 → 根 → 例」四步看：

1. **义**：全部中文意思，按词性排好；
2. **考**：考试词表、词频、柯林斯星级，标出优先记的义项；
3. **根**：词根词缀拆解 + 词源说明；
4. **例**：一句生活里用得上的例句，配中文。

另有：逐步讲解、生词本、闪卡复习、英音 / 美音朗读、夜间模式、考试词表筛选、A–Z 浏览。

当前词库：**35,877 词**  
其中 **7,977 个精讲词条**（有完整词义分析、词根词缀、记忆辅助） + **27,900 个简明词条**（释义、考试标签、词根拆解、例句按可用数据给出）。

## 完全离线：Mac 可以关机

不需要 Mac 一直开着。安装一次，下载离线词库后，iPad 可以断网使用。

### 1. 在 iPad Safari 打开安装地址

**[https://jin3768.github.io/ciye-wordbook/](https://jin3768.github.io/ciye-wordbook/)**

这是 GitHub Pages 的 HTTPS 地址。第一次打开需要联网，等页面正常出现「今日一词」。

> 这个页面来自一个临时公开仓库 `Jin3768/ciye-wordbook`，只放词典数据，没有个人信息。装好并下载离线包后，这个仓库可以删掉；已安装的 App 仍然能离线用。删掉后就不能再用这个网址重新安装了。

### 2. 添加到主屏幕

Safari 分享按钮 →「添加到主屏幕」。

### 3. 从主屏幕打开，下载离线词库

**一定从新出现的「词页」图标打开**（不要在 Safari 标签页里下载；独立窗口的本地存储是分开的）。

点右上角齿轮 →「完全离线」→「下载全部词库」，等状态变成：

```text
已下载 · 可离线使用
```

大约 20 MB，进度会显示在按钮和细线上。

### 4. 验证

打开飞行模式 / 关掉 Wi-Fi，从主屏幕打开「词页」：

- 能进首页；
- 能查 `abandon`、`summer`；
- 能打开词条。

这样就可以把 Mac 关机了。

> 如果之后清除 Safari 网站数据、删除主屏幕图标，或换一台 iPad，需要重新安装并下载离线包。
>
> 如果没有下载离线包，网页仍然可以在联网时使用；但断网打不开。

## 在 Mac 上本地运行（开发 / 备用）

双击 `start.command`，或者在终端：

```bash
cd "ciye 文件夹"
python3 server.py
```

终端会打印：

```text
本机   http://127.0.0.1:8788/
局域网 http://172.20.10.4:8788/
```

iPad 和 Mac 连同一个 Wi-Fi / 热点，Safari 打开「局域网」地址即可。局域网 HTTP 只能在线使用，不能安装离线 Service Worker。

如果局域网打不开：

- 确认 Mac 和 iPad 在同一网络；
- macOS 第一次可能询问是否允许 `python3` 接受传入连接，选择允许；
- 关闭 Mac 上的 VPN / 代理再试；
- IP 会随网络变化，以终端打印的为准。

## 怎么用

- **查词**：英文前缀 / 包含匹配；也支持中文反查（「放弃」「环境」）。
- **四步讲**：词条默认按「义、考、根、例」排好；右上角「逐步讲」可以一步一步看。
- **考试词表**：全部 / 中考 / 高考 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE；也可以按 A–Z 浏览。
- **熟词僻义**：address = 处理、company = 陪伴、fine = 罚款……考试里最容易错的义项单独标出。
- **生词本**：词条右上角星标收藏；「生词本 → 开始复习」进入闪卡。
- **朗读**：词条和例句上的喇叭按钮；设置里切换英音 / 美音。
- **夜间模式**：设置 → 阅读主题 → 夜间。
- **键盘**：`/` 聚焦搜索，`↑` `↓` 选词，`Enter` 打开，`Esc` 关闭。
- **简明词条**：带「简明」标记的词条没有长篇讲解，但仍有释义、考试标签、词根拆解和能拿到的例句。

## 数据说明

- **收词范围**参照你提供的《牛津高阶英汉双解词典（第 7 版，大字本）》PDF。该 PDF 的文字层是 OCR 的，直接抽释义会有大量识别噪声（音标、例句、标点都会乱），所以没有把 OCR 原文直接塞进词库；而是以它的收词范围为基准，用公开词书清洗、校对成可读的释义和讲解，再补上例句。
- 释义整理自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT）。
- 讲解（词义分析、词根词缀、记忆辅助）来自 [DictionaryByGPT4](https://github.com/Ceelog/DictionaryByGPT4)（CC BY-SA 4.0）。
- 部分例句来自 [Tatoeba](https://tatoeba.org)（CC BY 2.0 FR）。
- 这不是牛津大学出版社的官方产品；词库仅供个人学习使用。

### 为什么是 35,877 词，而不是 18 万全量？

牛津高阶有十几万词条，但 PDF 是 OCR 文字层，直接全量抽取会把音标、例句、标点弄乱，讲解质量无法保证。现在的做法是：

- **7,977 个精讲词条**：覆盖四六级、考研、高考、雅思托福 GRE 的主干词和高频常用词，优先保证讲解质量；
- **27,900 个简明词条**：把常用词、考试词补全，能查、能看中文意思、能看考试标签和词根；没有可靠例句的会明确写「例句还在补」。

极冷僻词没有硬塞进来，避免词库变成垃圾场。需要继续扩某个词表（比如考研大纲逐词、雅思全词）可以按同一管线继续加。

## 项目结构

```text
ciye/
├── start.command          # 本地启动
├── server.py              # 本地静态服务器（gzip、局域网）
├── README.md
├── web/                   # 可直接部署的静态站点
│   ├── index.html
│   ├── css/app.css
│   ├── js/{app,data,entry,util}.js
│   ├── data/
│   │   ├── index.json     # 搜索索引
│   │   ├── meta.json
│   │   └── w/a-z.json     # 按首字母分块的词条
│   ├── icons/
│   ├── manifest.webmanifest
│   └── sw.js
├── test/                  # Playwright / WebKit iPad 验收脚本
└── shots/                 # 验收截图
```

构建数据：

```text
../work/oxford/build_data.py    # 7,977 个精讲词条
../work/oxford/build_full.py    # 在精讲层上补 27,900 个简明词条
```

`build_full.py` 读取 `web/data` 现有的精讲层，再扫描 ECDICT 生成简明层；运行后会覆盖 `web/data`，旧数据备份在 `../work/oxford/data_rich_7977/`。
